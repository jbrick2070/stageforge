**Design choices proposed for adoption.** Start with 16 logical universes and retain the 1,024-unit total. Use a selected Art-Net source, a three-second preview timeout and a bounded batch queue. Use the specified IPv4 sACN level-data subset before broader conformance work. Keep portable packs declarative first. Treat measured photometric, structural and acoustic outputs as planning guidance. These choices are planning defaults. The cards identify the proofs needed to widen them.
