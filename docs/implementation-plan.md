## First milestone · Console preview

Each card is one reviewable increment. **P1 → P2 → P3 → P4** is the first milestone. P5 adds sACN input with source arbitration. P6 adds imported GDTF personality playback. Wider physical network output is scheduled independently (P7). The first public universe cap is **16 logical universes**, 512 slots each; values outside `1..16` produce a visible unsupported result. Widening later to 64 universes requires a measured workload and a fresh compatibility review. Baseline performance capture and deterministic test fixtures belong to P1.

### P1 · Resolve and display patch occupancy

**Document model and patching · Entry: when the existing queue reaches this plan.**

Preserve the current edit UI. Introduce one resolved per-unit patch record for hung and floor fixtures carrying parent-scoped identity, universe, start, footprint, and conflict/overflow status, and feed it to the patch list and diagnostic probe. Keep existing group spacing, defaults, and wire behavior unchanged. Identify duplicate group IDs by parent scope using collision-free structured keys (never bare `group.id` or unescaped `:` concatenation, which collide across pods or when a pod ID is `"floor"`), fixing parent scoping across `dmxPatch.ts` (`sameGroupSignature`), `StageEngine.ts` (`unitId`), `preflight.ts` (`placeKey`, `aimReachByGroup`, `liveByGroup`), `showPaperwork.ts`, and `powerReport.ts` while preserving existing serialized ordinal key formats for laser settings, audio mappings, and MVR interchange (`v1–v8` compatible). P1 derives a read-only key from parent, group, and ordinal with no serialized IDs added. D1 owns persistent IDs when overrides or external references require them; D2 owns Undo restoration.

**Acceptance**

Capture a legacy U1/U2 show containing one hung group, one floor group, a duplicate group ID on a second pod (including a pod with `id: "floor"` or a colon in its ID), and two instances of the same model. Verify prior/new resolved coordinates, monitor bytes, paperwork, preflight rows, and MVR UUIDs match within existing tolerances across repeated reads and label edits. A unit crossing slot 512 or overlapping another unit remains visibly invalid while a valid sibling in the same group remains patched. Capture baseline Arena Rock probe numbers at phone-like (`390×844`, 4× CPU throttle) and laptop settings, and save the fixture, before/after results, and commands in the sprint receipt. ### P3 · Desktop Art-Net input and monitor

**Desktop IPC and transport · Entry requires P2.**

Add explicit Start/Stop for Art-Net DMX input in the desktop editor, defaulting to loopback (`127.0.0.1`) and displaying selected interface, protocol, pinned sender address, mapped universe, frame age, and loss state. Reuse `decodeArtDmxPacket` and `desktop/artnet-rx.cjs`. Extend `artnet-rx.cjs` to track both bound `(port, address)` and in-flight opening `(port, address)` so incompatible interface/port requests (such as loopback DMX preview vs wildcard `0.0.0.0` Art-Net Timecode RX) are refused cleanly and a loopback socket is never widened silently. Retain existing Art-Net Timecode subscriptions when DMX RX stops.

For this release, pin one user-selected sender IPv4 address per universe; silence never transfers control to another sender. Mark a universe stale and dark after a 3-second preview timeout, resuming only on fresh frames from the pinned sender or an explicit source change. Map zero-based Art-Net Port-Address `0` to logical `U1` and `2` to `U3` under the default mapping. Validate sender, window access, and config options in main; allow up to 16 subscribed universes with one 512-byte snapshot per universe, at most one pending coalesced batch per window at up to 60 Hz, and fixed-size counters for dropped frames and unselected sources.

Extend `desktop/output-interlock.cjs` so the desktop AI bridge, physical lighting output (armed, live network, Art-Net discovery `dmx-control:discover`, and desktop Web Serial), and external DMX preview are mutually exclusive across all windows of the same desktop instance, reserving authority synchronously before any `await`. Keep DMX RX unavailable to Pitch Viewer and the web build.

**Acceptance**

A loopback producer updates `U3.001` in the monitor; an active Art-Net Timecode subscriber continues unaffected after DMX RX stops; a failed bind can be retried; late batches from a closed session are discarded; duplicate, out-of-order, disabled-sequence (`sequence === 0`), and short-frame (zero-padded tail) cases match the documented Art-Net 4 subset. Race start/stop/arm/discover across windows against network DMX output, AI bridge, and Web Serial (including port picker and teardown) in both directions during startup and pending shutdown. Verify release on failure, viewer entry, navigation, crash, unresponsive window, OS suspend/shutdown, close, and quit, and verify the receiver boots off after restart. ### P5 · sACN source arbitration

**Protocol and desktop · Entry requires P4.**

Harden and extend `decodeSacnPacket` at the existing receiver boundary for the E1.31-2018 IPv4 level-data subset: enforce `priority` in `0..200`, `universe` in `1..63999`, and accept 0-slot data packets (`Property Value Count === 1`, 126 bytes, used by 0-slot `Stream_Terminated` frames). Key active streams by `CID + universe`. Accept start-code `0x00` level data, select the highest universe priority, and HTP-merge ties per slot. Scope the first rendered demonstration to independent dimmer channels and report HTP merge behavior explicitly for non-dimmer attributes. Accept `Preview_Data`-flagged streams in visual-only preview and mark them clearly. Skip synchronization-dependent streams (`syncAddress !== 0` or `Force_Synchronization`), per-address priority (`0xdd`), and unsupported start codes with fixed-size diagnostic counters without mutating active output. Enforce E1.31-2018 §6.7.2 sequence ordering (discard packets when signed 8-bit `receivedSeq - lastSeq` is in `[-19, 0]`; accept `> 0` or `<= -20` across wrap).

Retire a source for a universe immediately on `Stream_Terminated` or after 2.5 s of silence using independent per-source expiry clocks and an injectable deterministic clock, recomputing the winner on retirement. Bind receive-only on explicitly selected interfaces. Cap tracked sources at 4 CIDs per universe across up to 16 subscribed universes: at capacity, admit a strictly higher-priority newcomer by evicting the lowest-priority source (breaking ties by oldest arrival); otherwise count and drop the newcomer. Confirm the supported subset against spec test vectors during implementation review.

**Acceptance**

Golden packets constructed independently of `encodeSacnPacket` covering two competing CIDs with unequal and equal priorities, a terminated winner (including 0-slot termination), source expiry either side of 2.5 s, sequence wrap and `[-19, 0]` out-of-order rejection, invalid priority/universe, short/malformed frames, reconnect, simultaneous universes, `4 → 5` source cap eviction, and zero retained allocations after Stop. Verify priority and merge independently of Art-Net and document exact feature scope. Use loopback and simulated multicast joins in CI. Reserve named console/version compatibility claims for dated captures. ESTA lists E1.31-2025 as the published revision. [ANSI E1.31-2018](https://tsp.esta.org/tsp/documents/docs/ANSI_E1-31-2018.pdf) · [ESTA published standards](https://tsp.esta.org/tsp/documents/published_docs.php)

## Implementation gate and handoff

1. **At pickup**, record `HEAD`, upstream queue position, card ID, prerequisites, and existing test fixtures. For persisted formats, declare the first schema or bundle version that represents the field and the minimum writer version when the field is absent. Released schemas are frozen; coordinate additive fields cleanly and test legacy files, mixed old/new fields, and consumer feature detection. Update Electron `exportsBySuffix` and file-open filters in `desktop/main.cjs` for any new desktop export or import format while keeping Pitch Viewer read-only.
2. **Before merging**, exercise fixture, editor, Pitch Viewer, and Electron checks through normal user entry points. Untrusted imports must validate and fail before mutating live state, leaving the prior show intact. Structural document mutations must execute the synchronous live-output stop barrier (`stopLiveOutputBeforeStructuralChange`), invalidate pre-flight acknowledgments, and require explicit re-arm. Optional rendering features must record before/after Arena Rock probe measurements (same scene, camera, tier, feature-off cost, p50/p95/p99, GPU/resource counts, and an explicit cap or fallback).
3. **Run the full project gate** at the candidate commit: `npx tsc --noEmit -p .`, `npm test`, `npm run build`, `npm run desktop:win`, `npm run test:desktop`, `npx playwright test --workers=1` (or `mac-gate.ps1` in parallel per `HANDOFF.md`), and `git status --short`. Run `codex-qa.ps1`, fix all verified findings with regression tests, and repeat QA + full gate on final code until `VERDICT: NO BLOCKERS`. The owner’s external pusher handles deployment; never run `git push`. Physical hardware and third-party console/tool witnesses qualify product claims separately from a green software sprint gate. Keep per-card evidence (input, expected, observed, commit, reviewer verdict) and use loopback for network automation.
4. **On failure**, keep the accepted reader and prior document usable, disable the incomplete optional surface, and hold the card. Never silently downgrade a newer-format file or serialize a partial model over it. Log remaining findings with a minimal reproducer.

**Desktop lifecycle for P3, E2, and E3.** Register an owner window (`webContents.id`), document revision, and session generation synchronously before opening sockets. On cancel, Pitch Viewer entry, show switch, navigation, `render-process-gone`, `unresponsive`, window `destroyed`/`closed`, OS `suspend`/`shutdown`/`session-end`, and `before-quit`, invalidate pending async work, stop advertisements, leave multicast groups, release socket listeners, and clean up staged files. Drop late callbacks and await full cleanup before admitting a new owner on the same endpoint. Test closing during a pending bind/join, transferring while entering Pitch Viewer, and restarting after cancellation. Bound a stalled renderer to one in-flight IPC batch plus one replaceable latest snapshot per selected universe, verifying bounded memory under stalled acknowledgments.

**First future assignment.** When the existing handoff queue releases and reaches this plan, assign **P1** to one implementer. Its demo is the existing patch and fixture views resolving independently identifiable per-unit records on a legacy rig with duplicate cross-pod group IDs, backed by before/after parity results and Arena Rock baseline metrics. **P2** is the first increment that expands what users can persist.
